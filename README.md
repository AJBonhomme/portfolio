# Antoine Bonhomme — Portfolio

Static portfolio site (HTML/CSS) deployed on Vercel.

- `*.html` — generated pages (clean URLs via `vercel.json`)
- `img/` — web-sized project images
- `src/` — generator: edit `src/content.py` (text, image picks, project order) and run `python3 src/build.py` with the extracted deck images available.
